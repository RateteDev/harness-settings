# スキル：ライト/ダークテーマ切り替え

画面描画時のちらつき（FOUC）を防ぎ、設定の保存・復元とアクセシビリティに配慮したテーマ切り替え機能を実装する。

---

## 仕様要件

### 1. 構成・スタイル
- **外部ライブラリ不使用**: Vanilla JSとCSSのみで実装する。
- **ボタン配置**: `<header>` 直下に直接置く（不要なラッパータグで囲まない）。
- **ボタンスタイル**: 背景・枠線・影は付けない（透明）。
- **アイコン（Lucide）**:
  - ライトテーマ時：月アイコンを表示
  - ダークテーマ時：太陽アイコンを表示
  - *参照方法*: 単体HTMLなら`<symbol>`と`<use>`を使用。ビルド環境がある場合はインラインSVGを展開。

### 2. テーマ管理ロジック
- **属性管理**: `<html data-theme="light|dark">` で管理する。
- **判定と保存**:
  1. **初回アクセス**: OSのテーマ設定（`prefers-color-scheme`）を取得して適用し、`localStorage` に保存。
  2. **再訪問時**: `localStorage` の保存値を最優先で適用。
  3. **切り替え時**: `data-theme`、アイコン、`aria-label`、`localStorage` を一括更新。

### 3. 表示・アクセシビリティ
- **ちらつき（FOUC）防止**: `<head>` 内の早期に実行されるスクリプトで初期テーマを判定・適用し、描画の乱れを防ぐ。
- **アニメーション**: 背景・文字・枠線色を `0.2s` で滑らかに切り替える。
- **配慮**: `prefers-reduced-motion: reduce` 設定時はトランジションを無効化する。

---

## 実装例

### HTML
```html
<header>
  <button id="theme-toggle" type="button" aria-label="ダークテーマに切り替える">
    <svg aria-hidden="true">
      <use href="#icon-moon"></use>
    </svg>
  </button>
</header>
```
