# 画像生成によるデザイン試行

画像生成でデザイン案を作成した際は、**後から完全に再現できるよう**作業フォルダに必要な素材・記録を残してください（これらは最終成果物zipに含まれます）。

### 記録・保存ルール

1. **プロンプト**
   - 実行した原文をデザイン案ごとに記録する。
   - 改訂・再生成した場合も初回プロンプトを保持し、各画像がどのプロンプトから生成されたかを明確にする。

2. **参照画像（Image-to-Imageなど）**
   - 参照元の情報（URLやファイル名）を記録し、参照した画像データ自体も作業フォルダに保存する。

3. **生成画像の掲載と評価**
   - 生成画像は加工せずそのまま掲載する。
   - ノイズ、崩れ、意図しない描写などの問題点は、画像ではなくテキストで記録する。

4. **後加工（スクリプト・組版）がある場合**
   - 純粋な生成画像と区別できるよう、加工工程を明記する。
   - 使用したスクリプトは作業フォルダに保存する（スクリプト内に一時パスを含む場合はその旨を注記する）。
