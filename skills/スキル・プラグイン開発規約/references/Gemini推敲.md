# Gemini推敲

Geminiを使用して、スキルのドキュメントを読みやすく推敲する手順です。
ユーザーから指示された場合のみ実行してください。

## 基本方針

- **Geminiの出力を最大限尊重する**
  言い回しや見出し、書式がスタイル規約と多少異なっていても、原則として修正しません。
- **致命的な不備のみ修正する**
  セクションの欠落、事実誤認、表示崩れなど、明らかな破損がある場合のみ手動で修正します。
- **frontmatterを維持する**
  スクリプト側で実行前のfrontmatterに自動復元されるため、変更不要です。

## 実行手順

1. **環境変数の確認**
   - `GEMINI_API_KEY` が設定されていることを確認します。

2. **スクリプトの実行**
   ```bash
   bun scripts/gemini-rewrite.ts <ファイルパス>...
   ```
   ※ オプションの詳細は `--help` で確認してください。

3. **差分の確認**
   - `git diff` で変更点を確認します。

## 注意事項

- **強調と句点の配置**
  強調記号の内側に句点があると、改行整形時に表示が崩れます。句点は必ず強調の外側に置いてください。
  （例: `**強調テキスト**。` とし、`**強調テキスト。**` とはしない）
- **モデルやシステムプロンプトの変更**
  これらはスクリプトの先頭で定義されています。設定を変更する際は、同一ファイルに対して変更前後の出力を比較・検証してから適用してください。
