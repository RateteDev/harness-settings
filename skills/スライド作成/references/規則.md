# スライド作成ルール

## 必須ルール

1. **1スライド1メッセージ**
   - 1枚に複数の主張を入れない。
     メッセージが増える場合はスライドを分ける。
   - 発表時間の目安は1スライド1分以内とする。

2. **見出し（`h1`）は1枚につき1つ**
   - 「〜について」などのラベルではなく、スライドの結論を単体で伝わる文にする。
   - 句読点は使わない。
   - 改行時に次行へ1文字だけ残さない（文節で改行するかフォントサイズで調整）。

3. **見出し直下のリード文は禁止**
   - 見出しの直後には要約を挟まず、根拠・具体例・データを直接配置する。

4. **視線誘導は「上から下」「左から右」に統一**
   - 読む順序が逆行・往復する配置を避ける。

5. **ページ番号は `nn/nn` 形式で隅に配置**
   - スライドの増減に対応できるよう、自動採番を前提とする。

6. **ヘッダーは全スライドで統一**
   - ヘッダーを設ける場合、位置・高さ・構成要素をデッキ全体で揃える。

---

## 任意ルール

- **インパクトスライド（強調・場面転換用）**
  - 背景色を反転させ、要点となる一言のみを大きく配置する。
  - 必須ではないが、作成する場合もページ番号は必ず配置する。
