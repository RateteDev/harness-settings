# README

公開リポジトリでは、初見の人が何のためのものか、どう試せるかを把握できるREADMEを用意する。非公開リポジトリでは必要に応じて作る。

- 本文の既定言語は日本語とし、ユーザーから指定があった場合だけ別の言語で書く。
- 冒頭で用途と対象を簡潔に伝え、試すために必要な前提・導入・最小の実行例へつなぐ。コマンドと動作は対象リポジトリで確認する。
- 機能や導入経路が複数あるときは、最短の入口を示し、詳しい説明は既存の文書へリンクする。見出しや機能一覧を増やすこと自体を目的にしない。
- コマンド例では各コマンド行の直前に、何をするかが分かる短いコメントを置く。
- 図は画像で示し、Mermaidは使わない。操作の流れを示すなら、実際の入力・操作・出力が追える具体的な画面や成果物を描き、抽象的なアイコンの連鎖だけで済ませない。図の表記をソースに照らして確認し、本文か代替テキストからも流れが分かるようにする。
- 公開前にライセンスを決めてライセンスファイルを用意し、READMEのライセンス欄から実際の条件へリンクする。ライセンスが未決定なら公開前にユーザーへ確認する。バッジは実際の配布先や状態に合うものを使う。
- 言語版へのリンクは、参照先のREADMEがある場合に置く。言語リンクやバッジが複数ある場合は原則として1行に2件ずつ並べ、長い項目は単独行にして、狭い画面でも読めるか確認する。
