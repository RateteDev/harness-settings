# テーマ切り替え

ライト/ダークのテーマ切り替えは、初期表示のちらつきや保存の取りこぼしなく動いて初めて成立するため、テーマの決定・保存・復元と表示の更新を一続きの動作として実装する。

## あるべき状態

### 構成

- テーマ管理は外部ライブラリを使わず、自前のスクリプトで実装する。
- 切り替えボタンはheader内に直接置き、余計なラッパーで包まない。

### アイコン

- アイコンはLucideの太陽・月を使い、ライト時は月、ダーク時は太陽を表示する。
- アイコンの参照方法は環境に合わせる。
  - 単体HTMLでは、HTML内にLucideのSVGを`<symbol>`で定義し、`<use href="#icon-moon">`で参照する。
  - 通常のWebサイトでは、`assets/icons/`に置いたSVGをビルド時にインライン展開する。
- ボタンには背景・枠・影を付けない。

### テーマの管理

- テーマは`<html data-theme="light|dark">`で管理する。
- 初回訪問時はOSのテーマを取得してlocalStorageに保存し、以降は保存値を優先し、切り替え時に保存値を更新する。
- 切り替え時に、JavaScriptでテーマ・アイコンの参照先・`aria-label`を更新する。

### 表示

- 初期表示でちらつかないようにする。
- 背景・文字・枠線の色が約0.2秒で滑らかに切り替わるようにする。
- `prefers-reduced-motion`を尊重する。

## 手段

ボタンは次の形で置く。

```html
<header>
  <button id="theme-toggle" type="button" aria-label="ダークテーマに切り替える">
    <svg aria-hidden="true">
      <use href="#icon-moon"></use>
    </svg>
  </button>
</header>
```
