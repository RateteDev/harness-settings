# 記事風HTML変換

## 目的
Markdown/MDXファイルを画像などの依存関係を含んだ単一のHTMLファイルへ変換し、どの環境でも同じ見た目で閲覧できるようにする。

## 前提条件
- `md-render` コマンドがインストールされていること。
  - コマンドが存在しない場合は作業を中断し、ユーザーに導入を確認すること。
  - 事前に `md-render --help` でオプション仕様を確認すること。
  - ※npmパッケージの `md-preview` は別物のため使用しない。

---

## 手順

### 1. HTMLへの変換
出力先は `.tmp/md-render/` とする。

```bash
mkdir -p .tmp/md-render
md-render \
  "<入力ファイル.mdx>" \
  --out ".tmp/md-render/<出力名>.html" \
  --media inline
```

- **メディア指定（`--media`）の基準**:
  - 原則: `--media inline`（ローカル画像などをHTML内に埋め込み、1ファイルで完結させる）
  - 例外: 外部の絶対URLを直接参照させたい場合のみ `--media link` を使用

### 2. 表示・出力の検証
変換完了後、以下を確認する。

1. **ファイル内容**: ファイルが空でなく、元のタイトルと本文が含まれているか。
2. **表示確認**: ブラウザで開き、見出し・目次・コードブロック・画像・表などが正しく描画されているか。
3. **パスの確認**: `--media inline` を指定した場合、ローカルのファイルパスがHTML内に残っていないか。

### 3. 公開・共有
生成したHTMLを外部URL等で共有する必要がある場合は、独自に配信先を判断せず、プロジェクト規定の公開手順に沿ってファイルを渡すこと。
