# Gemini推敲

Geminiを使用してスキル定義ファイルを推敲・整形する手順です。
**ユーザーから明示的な指示があった場合のみ**実行してください。

---

## 運用方針

- **Geminiの出力を原則そのまま採用する**: スタイル規約との軽微な差異は許容し、手動修正は最小限にします。
- **致命的な不備のみ修正する**: セクションの欠落・事実誤認・表示崩れがある場合のみ手動で直します。
- **frontmatterは触らない**: スクリプトが自動で元の内容を復元するため、変更不要です。

---

## 実行手順

1. **環境変数の確認**
   `GEMINI_API_KEY` が設定されていることを確認します。

2. **スクリプトの実行**
   ```bash
   bun scripts/gemini-rewrite.ts <対象ファイルのパス>...
   ```
   ※ オプションの詳細は `--help` を参照してください。

3. **差分の確認**
   `git diff` を実行し、意図通りの変更内容か確認します。

---

## 注意事項

- **強調と句点の配置**
  句点は強調構文の外側に置いてください（内側に入れると改行整形時に表示崩れの原因になります）。
  - ○: `**強調テキスト**。`
  - ×: `**強調テキスト。**`
- **プロンプトやモデルの調整**
  スクリプト先頭の設定を変更する場合は、同一ファイルで変更前後の出力を比較検証した上で反映してください。
