# スキル・プラグインの開発

スキルとプラグインは変更が速く、常設のテストや検証手順は維持費がかかる。開発時の確認はその場で行い、テスト・評価用ファイルやテスト専用のJustfileを成果物として残さない。

スクリプトとプラグインでは、入力・前提条件・外部応答を処理する時点で検証し、異常を検知する。実行できなかった場合は成功や対象外として扱わず、利用者に分かる経路で安全な失敗理由を伝える。セッションに紐づく失敗はその会話で伝え、処理を続けると誤認を招く場合は明示的に止める。秘密値や外部サービスの応答本文をそのまま通知しない。

`SKILL.md`を作成・編集するときは、[スキルの書き方](references/skill-writing.md)を読む。プラグインのOpenCode API仕様は`opencode`スキルを参照する。
