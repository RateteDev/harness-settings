# スライド作成

## 目的

1スライド1メッセージを徹底し、情報の詰め込みを防ぐ。
PC・スマホのどちらでも快適に閲覧でき、短時間で要点が伝わるスライド資料を作成する。

## 成果物の仕様

1. **HTMLデッキ**
   - 解像度：1920×1080（ビューア型、自己完結HTML）
   - 作成方法：`templates/スライド.html` を複製して作成。
   - スタイル：`templates/*テーマ.css` から1つを選び、`/* @theme */` の位置に展開する。
   - ※印刷・改ページ・ページ番号の自動採番が壊れるため、テンプレートのDOM構造や印刷用CSSは変更せず、テーマCSSのみで装飾すること。
2. **PDF**
   - 1スライドを1ページとして出力したPDFファイル。

## 作成ルール

### メッセージと見出し（h1）

- **1スライド1メッセージ**：1枚につき主張は1つ。主張が増える場合はスライドを分ける。
- **見出し（h1）の原則**：
  - 各スライドに `h1` を1つだけ配置し、メッセージ（結論）をそのまま記述する。
  - 「〜について」などのラベルではなく、単体で意味が通る事実・結論の文にする（句読点は不要）。
  - すべての `h1` を順に読むだけで、プレゼン全体の流れが把握できるようにする。
  - 改行する場合は、次行に2文字以上を残す（文字サイズや改行位置で調整）。
- **本文の構成**：
  - `h1` の直後は導入や要約文を挟まず、根拠・具体例・図表を直接配置する。
- **発話時間**：1スライドあたり1分以内を想定。超える場合は分割または情報削減を行う。

### レイアウト・視線誘導

- **視線順**：上から下、左から右へ自然に流れる配置にする。
- **ヘッダー**：設置する場合は全スライドで位置・高さ・構成を統一する。
- **ページ番号**：右下などに `nn/nn` 形式で表示（テンプレートの自動採番を使用）。
- **インパクトスライド（任意）**：
  - 山場や場面転換でのみ使用。
  - テンプレートの `.impact` クラスを使い、背景色反転＋一言を巨大表示する（ページ番号は必須）。

## 実装・出力手順

1. **構成の作成**
   本文を書く前に、全スライドの `h1` のみを並べて通読し、全体のストーリーラインを確定する。
2. **HTMLの実装**
   `templates/スライド.html` に選択したテーマCSSを展開し、コンテンツを実装する。
3. **PDFの出力**
   以下のスクリプトを実行してPDFを書き出す（要：`playwright-core`、Chromium）。
   ```bash
   node scripts/export-pdf.mjs <入力HTMLパス> <出力PDFパス>
   # 詳細なオプションは node scripts/export-pdf.mjs --help を参照
   ```
