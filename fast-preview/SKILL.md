# Fast Preview

開発中の画面を最短で見られる状態にし、まずURLを返す。速さの実体はモデル選択にあり、このスキルは手順の短縮だけを担う。モデルを速いものへ変えたい場合は、セッション側で切り替える。

## 手順

1. プロジェクトが既に持つ起動方法を使う。`package.json` の `scripts`、`justfile`、`Makefile`、フレームワーク設定の順に確認し、開発サーバを起動するコマンドを特定する。新しい起動方法を書かない。
2. runtime policy により package manager の直接実行は Bun・uv へ誘導される。`npm run <script>` ではなく `bun run <script>` を使う。
3. 開発サーバは shell tool の background で起動する。起動ログから待受URLを読み、回答の先頭でURLを提示する。
4. 目視確認が必要なときは `verify-codexoauth-gpt-6-luna-xhigh` へ委譲する。対象URL、シナリオ、期待結果、証跡の形式を渡す。メインの `browser` 権限は deny のため、メインはブラウザを直接操作しない。
5. テスト・lint・型チェック・リファクタリングは、ユーザーが求めたときだけ行う。

## 失敗したとき

起動できなかった場合は、成功として扱わず、ポート衝突・依存未導入・コマンド誤りのどれかを切り分けて原因を報告する。
