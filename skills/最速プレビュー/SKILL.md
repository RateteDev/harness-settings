# 最速プレビュー

## 目的
実装後の手戻りを防ぐため、ロジック実装やテストに先立って視覚的なプレビューを提示し、UIの方向性・構成を早期に確定させる。

## 手順
UIの変更を伴うタスクでは、本実装前に以下の流れで進行する。

1. **手段の選定**  
   状況に応じ、最も早くプレビューを見せられる方法を1つ選ぶ。
   - 単体のHTML/CSSモックを作成する
   - Git worktree等を使い、開発サーバーを立ち上げる
   - ブラウザ上で要素を直接注入/置換する

2. **プレビューの提示と合意**  
   ユーザーに見栄えを提示し、UIの方向性について合意を得る。

3. **本実装の開始**  
   合意が得られた後に、詳細なロジック実装やテストへ進む。
