# 画像生成

AIビットマップ画像（写真・イラスト・テクスチャ等）を新規作成するときに使う。インストール済みの `imagegen` コマンドが Codex の画像生成エンドポイントを呼び、PNGを保存してパスを返す。

## 事前準備

```bash
bun add -g github:RateteDev/chatgpt-auth-for-responses
```

`imagegen` がPATHに無い場合、上記でインストールする。認証は `~/.codex/auth.json`（`codex --login` で生成）のトークンを使う。

## 実行方法

```bash
imagegen "<プロンプト>" [options]
```

最後に**保存パス**（`--json` ならJSON）が標準出力される。それをユーザーへ報告する。

## オプション

| オプション | 説明 |
|---|---|
| `--model <slug>` | 画像モデル（既定: `gpt-image-2`） |
| `--size <size>` | サイズ例 `1024x1536`（既定: `auto`） |
| `--quality <q>` | `low`/`medium`/`high`/`auto`（既定: `auto`） |
| `--background <bg>` | `transparent`/`opaque`/`auto`（既定: `auto`） |
| `--n <count>` | 生成枚数 |
| `--output <path>` | 保存先（既定: `./generated_images/imagegen-<ts>.png`） |
| `--auth-file <path>` | `auth.json` パス（既定: `~/.codex/auth.json`） |
| `--json` | パス等を機械可読JSONで出力 |

## 出力の扱い

- 既定の保存先は `./generated_images/imagegen-<ts>.png`。`--output` で好きな場所へ書ける
- **プレビュー用途**ならそのままパスを報告する
- **プロジェクトで使う場合**は、生成後に成果物をワークスペースへコピーし、参照や消費コードを更新する。既定の保存先にだけ置いたままにしない
- 既定の保存先は削除せず残す。削除はユーザーが明示したときのみ

## プロンプトの書き方

具体的に書くほど品質が安定する。以下を明示すると再現しやすい。

- 被写体・構図・アングル・照明・時間帯
- スタイル（フォトリアル / イラスト / 3D等）と色調
- 生成サイズ（`--size`）と品質（`--quality`）が要る場合はオプションで指定

1枚の成果物を複数バリエーションで作る場合は、`--n` ではなくプロンプトを分けて1回ずつ呼ぶ（`--n` は同一プロンプトの変種向け）。

## 制約と注意

- エンドポイントは非公開で、Cloudflareのボット保護により**断続的に404**を返すことがある。404が出たら時間をおいて再試行する
- `auto` はサーバー側で解決される（2026-09-03時点: `size=1536x1024` / `quality=low`）
- 編集（既存画像の改変）は現状このCLIでは未対応。必要になったら `--output` の使い方と代替を伝える
- ベクター・アイコン等、コードネイティブなアセットや html/css で作るべきものには使わない
