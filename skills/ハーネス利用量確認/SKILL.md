# ツール利用量確認

## 目的
認証情報や機密データを露出させずに、各ツールの利用状況（クォータ、トークン消費量、推定コスト）を取得・報告する。

## 手順

1. **スクリプトの実行**  
   確認対象のツールに応じたスクリプトを実行する。
   ```sh
   # Claude Code
   scripts/claude-code-usage.sh

   # Codex / ChatGPT
   scripts/codex-usage.sh

   # OpenCode
   scripts/opencode-go-usage.sh
   ```

2. **結果の報告**  
   取得結果を報告する。
   その際、データが**「現在のリアルタイムクォータ（残量）」**なのか**「ローカルの使用履歴」**なのかを明記する。

## 制約・注意事項
- **機密情報の保護**: APIキー、トークン、パスワード、プロンプト、実行ログの内容は絶対に出力・保存しないこと。
- **トラブルシューティング**: エラー発生時や認証設定の確認が必要な場合は、事前に `references/<対象ツール名>.md` を参照すること。
