# Jev検索

## 概要
候補が大量にある場合、エージェント自身がすべて読み込むとコンテキストと処理時間を大幅に消費します。
Jev（TypeSafe社）を使って事前に候補の関連度を判定・ソートし、精読すべき対象を絞り込みます。

## 利用手順

候補が多い検索・選定タスクでは、自分で精読を始める前にJevを実行してください。

### 1. 仕様確認
初めにヘルプで入力・出力形式を確認します。
```sh
jev --help
```

### 2. 実行のポイント
- **入力形式**: 候補を「1行1件」で記述したファイルを渡す。
- **精度向上のコツ**: 1行の中にタイトルだけでなく、プロンプトや本文の抜粋も含めると判定精度が向上する。
- **出力形式**: 関連度の高い順に並んだTSV形式で返る。

### 3. コストと報告
- **課金**: `TYPESAFE_API_KEY` を使用し、候補数と入力量に応じた従量課金が発生します。
- **ユーザーへの報告**: Jevを使用した場合は、その旨と選定結果・効果を回答内で簡潔に伝えてください。
