# 画像生成によるデザインの試行錯誤

画像生成で案を作った場合は、あとから同じ作り方を再現できる材料が作業フォルダに残っている状態にする。
材料は原本zipに入る。

- プロンプトは、実行した原文のまま案ごとに記録へ残っている。
  改訂で画像を上書きした場合も初回の指示が残り、掲載した画像がどの指示の結果かが分かる。
- 参照画像を渡して作った案は、参照元が記録され、参照素材も作業フォルダにある。
- 生成した画像は手を加えずに図として掲載され、汚れや崩れなどの問題は記録に文章で書かれている。
- 生成後に組版やコードで仕上げた案がある場合は、画像生成だけの案と区別できるように作り方が示され、使ったスクリプトが作業フォルダにある。
  スクリプトに一時パスが含まれる場合は、その旨が添えられている。
