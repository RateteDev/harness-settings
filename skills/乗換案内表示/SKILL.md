# 乗換案内表示

## このスキルの目的

乗換案内をそのつど手でHTMLに書くと、トークンを消費し、見た目も毎回揺れる。
検索した経路をJSONに写して渡すだけで、Googleマップの乗換案内に似た縦タイムラインの自己完結HTMLを得る。

## あるべき状態

- 経路の検索・取得はこのスキルに含めず、検索結果を読んだエージェントがJSONへ写す。
- HTMLは手で書かず、`scripts/render.ts`で生成する。
  見た目の変更は`templates/*.css`だけで行う。
- 入力JSONは`templates/例.json`を複製して作り、画面に出ている値をそのまま写す。
- 導出できる値は書かない。
  所要時間・乗車時間・徒歩の合計・駅ごとの時刻の行・概要欄の路線の並びは、レンダラが算出する。
- 路線の`色`は、`references/路線色.json`を路線名で検索し、該当行の`色`を写す。
  表は全体を読まず、検索で該当行だけを引く（例: `rg '東海道' references/路線色.json`）。
- 表にない路線や、表と実際の表示が合わない路線の色は、検索か推測で決めてよい。
  色はユーザーへ報告も確認もせず、決められなければ`色`を省く（中立のグレーで描かれる）。
- 出力はモバイル幅（408px基準）の縦長1列とする。

## 手段

- 生成: `bun scripts/render.ts 入力.json -o 出力.html`。
  入力の誤りは、場所と理由を示して終了コード1で止まる。
- 入力の項目（`経路`は時刻順に並べる）:

  | 項目 | 必須 | 内容 |
  |---|---|---|
  | `出発地`・`目的地` | ○ | `名称`（必須）と`住所` |
  | `出発`・`到着` | ○ | `H:MM`か`HH:MM` |
  | `運賃` | ○ | 円の整数 |
  | `経路[]`の`種類:"徒歩"` | | `分`（必須）、`メートル` |
  | `経路[]`の`種類:"乗車"` | | `路線`・`行先`・`発`・`着`（駅と時刻）が必須 |
  | 乗車の任意項目 | | `色`（`#rrggbb`）、`記号`（JTなど）、`種別`（急行など）、`停車駅`、`定刻`（真偽）、`ホーム`、`乗換地点ID` |

- `行先`・`停車駅`・`ホーム`は、画面の表記をそのまま入れる（例: `和光市行`、`途中停車駅なし`、`4 駅乗車`、`2 番ホーム`）。
- 概要欄は3分未満の徒歩の記号を省く。
  Googleマップで乗換の徒歩2分が省かれ、4分が表示された観測に基づく。
