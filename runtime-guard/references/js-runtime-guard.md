# JS ランタイムガード

`npm` / `npx` / `pnpm` / `pnpx` の直接実行を抑止し、Bun への移行を促すガード。本当に必要なときの迂回路として `real-*` を提供する。

## 管理対象
| ファイル | 役割 |
|----------|------|
| `scripts/js-runtime-guard.sh` | 本体（呼び出し名で「ガード」「迂回路」「使い方表示」を振り分ける） |
| `~/.local/bin/{npm,npx,pnpm,pnpx,real-npm,real-npx,real-pnpm,real-pnpx}` | 上記スクリプトへのシンボリックリンク 8 本 |

## 背景
`npm install` 等が無造作に実行されると bun ベースの開発体験が崩れるため、PATH 先頭付近に置いたガードで直接実行を遮断する。

## 前提
- `~/.local/bin/` が PATH の前方にあり、本物より先にガードが解決されること
- bun を別途インストール済みであること（未導入でもガード自体は機能する）

## 派閥切り替え
pnpm 派・yarn 派などに切り替える場合は、スクリプト内の `REPLACE` 連想配列を直接書き換える（設定ファイルは持たない方針）。
