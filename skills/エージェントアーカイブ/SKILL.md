# エージェントアーカイブ

## 概要と基本原則

会話データのアーカイブや抽出には、必ず公式CLIツール `agent-archive` を使用してください。
ツールの仕様変更による破損を防ぐため、**ローカルDBや内部ファイルを直接参照・変更してはいけません。**

## 実行手順

1. **利用可能なサブコマンドの確認**
   まずは全体ヘルプを実行し、コマンド構成を確認します。
   ```sh
   agent-archive --help
   ```

2. **サブコマンドの仕様確認**
   目的に応じたサブコマンドを選び、引数やオプションを確認します。
   ```sh
   agent-archive <subcommand> --help
   ```

3. **実行**
   ヘルプに表示された使用方法に従ってコマンドを実行します。
