# 試行錯誤アーカイブ

試行錯誤アーカイブは、試したことと判断の経過を、記録・図・素材を内包した1つの自己完結HTMLにまとめたものである。読むためのもの（記録・図）を前、残すためのもの（素材）を後ろに置く。HTMLは読者エージェント向けの説明書を持つ。

汎用の規則はこのスキルに置き、題材でだけ決まることは題材ディレクトリの `AGENTS.md` に書く。作業によって読む先が違う。

- アーカイブを作る・整理する → [アーカイブを作る](references/making.md)
- アーカイブHTMLを読む → [アーカイブHTMLを読む](references/reading.md)
- 画像生成で案を作った → [画像生成によるデザインの試行錯誤](references/imagegen-design.md)
