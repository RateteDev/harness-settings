# アクセシビリティ

指針本体に書かれた基本姿勢・見出し階層・アイコンの `aria-label`・アップロードUIのネイティブ要素保持は、ここでは繰り返さない。

## セマンティックHTML

要素は視覚効果ではなく意味で選ぶ。
`div` / `span` の濫用を避け、`button` / `a` / `ul` / `li` など意味に応じたタグを使う。

## ARIA・支援技術対応

- キーボード操作・フォーカスリングを損なわない実装にする。
  独自コンポーネントでネイティブ要素を置き換える場合も、同等の操作性を担保する。

## 禁止事項

- 視覚的な見た目のためだけに見出しタグ・セマンティック要素を選択/省略しない。
- キーボード操作・スクリーンリーダー対応を損なうカスタムUIへの完全置換。
