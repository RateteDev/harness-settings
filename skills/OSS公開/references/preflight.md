# 公開前チェック

以下のすべての点検項目をクリアするまで公開を行ってはならない。

## 1. 秘密情報・環境情報の検査（担当：エージェント）

現在のファイル群およびGit履歴全体（削除済みファイル含む）に、秘密情報・個人情報・端末固有情報が含まれていないか確認する。
※Git履歴をゼロから再作成（初期化）する場合は本ステップをスキップ可。

- **実行コマンド**: `scripts/audit.sh <repo>`
- **報告時の注意**: 秘密情報を検出した場合、**値そのものは出力せず**、該当ファイルパスと情報の種類のみを報告すること。

## 2. 権利関係の確認（担当：ユーザー）

対象のソースコード、画像・音声等の素材、依存ライブラリについて、公開および再配布のライセンス上の問題がないかユーザーに確認を求める。

## 3. 再現性の検証（担当：エージェント／一部ユーザー）

新規作成したPodmanコンテナ環境にて、READMEの手順に従いインストールから実行まで検証する。

- **リポジトリ参照の切り替え**: `github:` 経由の依存指定は未公開時に認証エラーとなるため、ローカルパス参照に置き換えて検証する。
- **ユーザー対応項目**: 対話認証や実アカウント・実機が必要な手順は、エージェント側では実行せずユーザーに実施を依頼する。

---

## 点検チェックリスト

- [ ] `scripts/audit.sh` を実行し、コードおよびGit履歴に秘密情報・環境情報がない
- [ ] 権利関係・ライセンスに問題がない（ユーザー確認済み）
- [ ] クリーンなPodman環境で、READMEの手順通りに導入から実行まで完了した
- [ ] 対話認証や実機を伴う手順が正常に完了した（ユーザー確認済み）
