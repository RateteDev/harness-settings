# Color Palettes

Each palette defines a complete set of CSS custom properties.
Apply by setting `data-theme` on the root element.

## Snow (white)

Pure white base. Light default.

```css
[data-theme="snow"] {
  --color-bg:          #ffffff;
  --color-surface:     #f7f7f7;
  --color-surface-alt: #f0f0f0;
  --color-text:        #1c1c1c;
  --color-text-muted:  #6e6e6e;
  --color-primary:     #4a4a4a;
  --color-primary-hover: #333333;
  --color-border:      #e0e0e0;
  --color-border-strong: #c0c0c0;
  --color-accent:      #7a7a7a;
  --color-error:       #c4493c;
  --color-success:     #4a7c59;
  --color-warning:     #b8860b;
  --color-focus-ring:  rgba(74, 74, 74, 0.4);
}
```

## Stone (gray)

```css

  --color-surface:     #474747;
  --color-surface-alt: #535353;
  --color-text:        #dcdcdc;
  --color-text-muted:  #9a9a9a;
  --color-primary:     #a8a8a8;
  --color-primary-hover: #c4c4c4;
  --color-border:      #5e5e5e;
  --color-border-strong: #727272;
  --color-accent:      #959595;
  --color-error:       #e07068;
  --color-success:     #6aaa78;
  --color-warning:     #d4a64b;
  --color-focus-ring:  rgba(168, 168, 168, 0.4);

```
