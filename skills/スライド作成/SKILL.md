# スライド作成

## このスキルの目的

1枚に情報を詰めると、読み手はどこを見ればよいか分からず、伝わるべきメッセージが埋もれる。
1スライド1メッセージを軸に構成と配置を固定し、PCでもスマホでも同じ内容が読める資料にする。

## 進め方

成果物は、1920×1080の自己完結HTMLデッキ（ビューア型）と、そのPDFとする。

### テンプレートから作る

`templates/スライド.html` を複製し、`templates/*テーマ.css` から1つ選んで `/* @theme */` の位置へ展開する。
表示・送り・印刷・ページ番号の仕組みはテンプレートが持つので作り直さない。
デザインを変えるときはテーマのCSSだけを差し替える。

### 構成を先に固める

本文を書く前に、各スライドの `h1`（メッセージ）だけを並べる。
並べた見出しを続けて読み、話の流れと1枚1メッセージになっているかを確かめてから、本文を足す。

### 書くとき

`references/規則.md` の必須規則に従う。
見出しはラベルではなく、そのスライドの結論を述べる文にする。
見出しの直後にリード文を置かず、根拠・補足・具体物を直接置く。

### PDFにする

`scripts/export-pdf.mjs` で印刷メディアに切り替え、1スライド=1ページのPDFを出力する。

### 仕上げ

`references/規則.md` の自己点検を上から順に確認する。
