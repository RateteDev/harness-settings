# Jev

依頼との意味的な関連度で、多数の候補から調べる対象を選ぶ。

## 使う場面

- 過去セッションやアーカイブから、依頼に関係する会話を探す。
- DBレコードや文書の集合から、依頼に合う候補を探す。
- ログやファイルなど、候補の表現が依頼文と異なる対象を比較・評価する。

## 使い方

最初に次を実行して、候補の渡し方と出力形式を確認する。

```sh
jev --help
```

候補は1行1件のファイルで渡し、関連度の高い順にTSVで返る。呼び出しは`TYPESAFE_API_KEY`を使い、候補数と入力量に応じて従量課金が発生する。
