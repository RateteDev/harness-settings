# TypeScript

`references/typescript.md` に規約の本文がある。次のいずれかを決める・確認する必要が生じた時点で読む。

- ランタイムの選定
- lint / format ツールの構成と設定
- テスト実行の構成
- ロガーの選定と使い方
- `packages/` 配下を新規に初期化する手順

ツールの選定はプロジェクト単位で固定し、その場の判断で変えない。既存の構成に合わせるだけで済む場合、参照は不要。
