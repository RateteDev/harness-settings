# スライド作成

## このスキルの目的

1枚に情報を詰めると、読み手はどこを見ればよいか分からず、伝わるべきメッセージが埋もれる。
1スライド1メッセージを軸に構成と配置を固定し、PCでもスマホでも同じ内容が読める資料にする。

## あるべき状態

### 成果物

- 成果物は、1920×1080の自己完結HTMLデッキ（ビューア型）と、1スライドを1ページにしたそのPDFである。
- HTMLは`templates/スライド.html`を複製したもので、`templates/*テーマ.css`から選んだ1つのテーマが`/* @theme */`の位置に展開されている。
- 表示・送り・印刷・ページ番号の仕組みはテンプレートのままで、デザインの変更はテーマのCSSだけにある。
  PDFの書き出しとページ番号の採番が、テンプレートの構造と印刷用CSSに依存するためである。

### メッセージと見出し

- 各スライドは、伝えるメッセージを1つだけ持つ。
  2つの主張を1枚に置くとどちらも伝わらないため、主張が増えたら枚数を増やす。
- 各スライドに`h1`が1つあり、そのスライドのメッセージをそのまま書いている。
- `h1`は句読点を含まず、単体で意味が通る事実の文である。
  「〜について」「〜の話」のようなラベルではなく、読み手が結論を受け取れる文にする。
- `h1`だけを順に読むと、話の流れが通る。
- `h1`を折り返す場合は、次行に2文字以上が残る。
  折り返し位置か文字サイズで調整する。
- `h1`の直後には、根拠・補足・具体物が直接続く。
  要約や導入のリード文を挟むと、見出しと本文が二重になるためである。
- 1スライドの想定発話は1分以内である。
  1分を超えるなら、メッセージを分けるか情報を削る。

### 配置

- 1枚の中で、読む順が上から下、左から右に流れている。
- ページ番号が`nn/nn`の形で隅にあり、並び順から自動採番されている。
  枚数を足しても番号を直さずに済むようにするためである。
- headerを設ける場合は、位置・高さ・要素の構成が全スライドで揃っている。
- インパクトスライドは任意の要素で、山場や転換に使う場合だけ置く。
  地を反転し、一言だけを大きく置き、ページ番号も持つ。

## 手段

- 構成は、本文を書く前に全スライドの`h1`だけを並べて通読すると固めやすい。
- インパクトスライドは、テンプレートの`.impact`クラスで作る。
- PDFは`scripts/export-pdf.mjs`で書き出す。
  印刷メディアに切り替えて1スライド1ページで出力し、使い方は`--help`が示す。
  `playwright-core`とChromiumが必要である。
