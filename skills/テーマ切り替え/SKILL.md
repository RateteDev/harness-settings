# テーマ切り替え

## このスキルの目的

テーマ切り替えは、初期表示のちらつきや保存の取りこぼしなく動いて初めて成立する。
テーマの決定・保存・復元と表示の更新を一続きの動作として実装する。

## あるべき状態

### 構成

- テーマ管理は外部ライブラリを使わず、自前のスクリプトで実装されている。
- 既存サイトのデザインや構成は維持されている。
- 切り替えボタンはheader内に直接あり、余計なラッパーを持たない。

### アイコン

- アイコンはLucideの太陽・月で、ライト時は月、ダーク時は太陽が表示される。
- アイコンの参照方法は環境に合っている。
  - 単体HTMLでは、HTML内にLucideのSVGを`<symbol>`で定義し、`<use href="#icon-moon">`で参照している。
  - 通常のWebサイトでは、`assets/icons/`に置いたSVGをビルド時にインライン展開している。
- ボタンに背景・枠・影が無い。

### テーマの管理

- テーマは`<html data-theme="light|dark">`で管理されている。
- 初回訪問時はOSのテーマを取得してlocalStorageに保存し、以降は保存値を優先し、切り替え時に保存値を更新している。
- 切り替え時に、JavaScriptがテーマ・アイコンの参照先・`aria-label`を更新している。

### 表示

- 初期表示時にちらつきが無い。
- 背景・文字・枠線の色が約0.2秒で滑らかに切り替わる。
- `prefers-reduced-motion`が尊重されている。

## 手段

ボタンは次の形で置く。

```html
<header>
  <button id="theme-toggle" type="button" aria-label="ダークテーマに切り替える">
    <svg aria-hidden="true">
      <use href="#icon-moon"></use>
    </svg>
  </button>
</header>
```
